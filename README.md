# Gryph Labs Organization Profile

This repository contains the public GitHub organization profile for **Gryph Labs**.

The rendered organization profile lives at `profile/README.md`.

## Repository purpose

Keep only organization-wide GitHub profile/community material here. Product source belongs in its own project repository.

## Change policy

Gryph Labs' Phoenix governance includes an accepted non-bypassable rule that repository changes use branch + pull request flow. This initial repository bootstrap establishes the base branch so future changes can follow that workflow.
