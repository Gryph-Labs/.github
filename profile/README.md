## About Gryph Labs

Gryph Labs builds practical software systems around AI-assisted engineering, automation, and developer tooling. Our work emphasizes understandable architecture, measurable behavior, strong review gates, and systems that can evolve without sacrificing control.

## Current work

### Phoenix
An AI software-delivery organization and product architecture for coordinating persistent AI employees, role-based authority, project knowledge, delivery workflows, model evaluation, memory, metrics, and human approval gates.

### Gryph Engine
A Java-based game engine with a separate JavaFX desktop editor, ECS-aligned runtime, dedicated OpenGL render thread, scene persistence, asset pipeline, and incremental editor tooling.

## Engineering principles

- **Architecture before accidental complexity.** Build the smallest structure that preserves clear boundaries.
- **Evidence over assumptions.** Validate models, workflows, and architecture with real project behavior.
- **Human authority where it matters.** Sensitive and production-impacting decisions retain deliberate approval gates.
- **Small, reviewable changes.** Repository work is designed for focused review and traceability.
- **Knowledge has an owner.** Durable documentation, executable work, and source code each live in the system best suited to them.
- **Security is a design constraint.** Least privilege, attributable access, and controlled secrets are part of the architecture rather than afterthoughts.
